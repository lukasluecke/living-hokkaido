# src/shell: composition shell

Owns `ExperienceState` (`state.ts`), journal progress and stamps
(`progress.ts`), the season clock and journal persistence (`Shell.tsx`), and
which component renders each part (`registry.ts`). Route: `/shell`.

- Parts are mounted with props from `src/contracts/parts.ts`; the shell is the
  only place that reads `localStorage` or holds state.
- `state.ts` and `progress.ts` stay pure functions with tests in
  `tests/contracts.test.ts`. Add a case there for every new event.
- To integrate a part, change code inside `src/parts/<part>/` and keep its
  export name. Only edit `registry.ts` to swap a whole implementation (for
  example a lazy-loaded 3D version with the HTML stub as fallback).
- Canvas layout (one shared canvas vs one per part) is an integration
  decision; record it here under "Decisions" when made.

## Decisions

- 2026-11-25: one canvas per 3D part (island, detail-scene, artifact viewer). The shell gives a full-screen stage, a HUD, a side slot (viewer, activity) and an overlay slot (journal, reveal).
- 2026-11-25: demo/e2e hook in `Shell.tsx`: every event is mirrored as a `lh:event` DOM event, `window.__livingHokkaido.emit` sends events, `<main>` has `data-view` and `data-overlay` (for `scripts/demo-video`, PR #8). Sound hook-up from PR #7 (`src/audio/AGENTS.md`) is kept when that PR merges.
- 2026-11-25: "Ask the owl" (`src/parts/ask`, docs/ASK.md) is mounted in `Shell.tsx` next to the guide line, with `view`, `locationId`, `sceneId`, `artifactId` and `covered` (an overlay is open). It sends only existing events.
- 2026-11-25: lazy parts (performance). `registry.ts` loads the island and
  ask with the page and every other part with `next/dynamic`;
  `preloadParts()` fetches them about 1.5 s after the shell mounts (idle).
  First-load JS 727 → 603 KB gzip.
- 2026-11-26: keyboard and focus (accessibility pass). Overlays (journal, reveal, timeline) are modal: stage, HUD and side slot get `inert`, focus moves to the first control inside (unless the part already focused one) and returns to the opener on close. `SidePanel` takes focus when it opens and gives it back to the opener when it closes; arrow keys still step objects while the panel itself has focus (`data-arrow-steps`). With `header={false}` the panel has no name, so the activity section is the only named region.
- 2026-11-26: tester feedback (Lukas). The shell starts in winter (`WINTER` in `state.ts`). On load, a 3.6 s intro timelapse runs spring → winter by setting the shell's season value directly (no `season.set`, so no stamp and no cue); a click, tap or key skips to winter, a visitor or script `season.set`/`season.play` stops it, reduced motion skips it. The HUD season button shows the season name as a chip on wide screens.
- 2026-11-26: HUD tools (Lukas): あ/EN, stamps, a sound button, the season chip (seasons, timelapse, over time) and a ☰ menu (contribute, demo note). On phones the sound toggle moves into ☰; at ≤380 px the tools shrink to 32 px. Side panel starts at 76 px, below the HUD; its header uses icons so arrows, title and × share one centre line.
- 2026-11-26: Lukas: no intro timelapse; the shell just starts in winter. The island shows light snowfall that comes and goes in winter instead (`Weather` in `src/parts/island/world/Environment.tsx`).
- 2026-11-26: owl tour start (Lukas's bug report). The welcome line shows only on the first look at the island: picking a place or a highlight clears it, so it never returns (or gets read out) later. No owl bubble or voice while the owl flies; the arrival line follows. ☰ menu has "Reset progress" (tap twice): it removes the saved journal (`JOURNAL_STORAGE_KEY`), keeps language and sound, and reloads, so the demo starts with the welcome again. One owl line per moment: in the highlight's own place the owl says the highlight line; elsewhere it keeps the place's own lines. Free exploring: a place you pick yourself (`location.select`, `touring: false`) pauses the tour there; the island and the highlight row offer it again. Through the tour (`highlight.open`, `touring: true`) the owl points on to the next highlight.
- 2026-11-26: the tour reads as one story (Lukas). The grove step is the film: its line names the film and then the tonkori. On the tour, once a place's own highlights are done, the owl says the next highlight's line (not the place line), so each line follows the one before. Voice files made from older text are not played (hash check in `src/audio/voice.ts`); run `npm run audio:voices` to make them again.
- 2026-11-26: tour film step (Lukas: "open the film card right away, and only after talk about the tonkori"). `highlight.open` for a film opens the scene's film card on landing (`ExperienceState.filmOpen`). The film part emits `film.open` / `film.close` (close also when the video ends); `film.close` adds the place to `journal.filmsSeen`, and only that marks the film highlight done. While the film is open the owl bubble and voice are hidden; after it closes, the owl offers the tonkori ("Now try the tonkori…", voice file from before #127 restored).
- 2026-11-26: first screen, progressive disclosure (Lukas: "quite overwhelming" on mobile). Before the first visit (`journal.visited` empty) the island view is calm: the owl bubble with its one step and an "Explore freely" link; no route rail, no Ask the owl, no place tray and no place labels (`IslandPartProps.calm`; phone and desktop; the 3D places still glow and take taps). One owl: the bubble has "Ask me a question" (opens Ask the owl; its own button shows only when the bubble does not), and answers end with "Back to the tour" while the owl has a next step (`AskPartProps.openSignal`, `hideTrigger`, `backLabel`). "Explore freely" (shell state, not saved) or any first visit shows the full UI. Season switcher hidden (`SHOW_SEASON_MENU` in `Hud.tsx`, winter fixed); "Over time" is in the ☰ menu inside a place with a timeline, and still in the highlight row and the scene signpost. `scripts/demo-video` still clicks "Timelapse"; set the flag to true before you record with it.
- 2026-11-26: tour start (Lukas). On the first look the island emits `island.ready` (first frame, or the HTML list); then a card says "Starting the tour in 3…" with Start now and Cancel (= Explore freely), while the camera frames the owl at its home (`IslandPartProps.closeUp`). At 0 or Start now the owl bubble shows (larger in calm), the owl speaks and the camera pulls out to the overview (a cut with reduced motion). The bubble has Pause / Resume for the voice-over (`pauseVoiceLine` / `resumeVoiceLine` in `src/audio/voice.ts`); a new line while paused waits until Resume. Browsers still block sound until the first tap; Start now counts as that tap.
- 2026-11-26: one card at the top (Lukas: the owl tour card is most important). The stamp toast shows low, above the tray (230 px from the bottom; 290 px on phones, above the place's clip or film card). On phones the place's clip card sits above the tray like the film card (`.clip` in `detail-scene/Scene.module.css`), so only the owl bubble is at the top.
- 2026-11-26: tour way on (Lukas: "how to proceed beyond [the diorama]?", "is there a skip?"). An open highlight activity on the tour shows "Next: <next highlight>" at the top of its panel. Closing a highlight activity on the tour, done or not, adds it to `ExperienceState.tourPassed` (session only), so the tour goes on. The owl bubble has "Skip this step" (`highlight.skip`, additive) on every tour step. Neither marks the step done in the journal.
- 2026-11-26: Lukas: the tour ends with the slide game. `Highlight.tour` (default true, additive); Out of Place has `tour: false`, so it stays in the highlight row and the coast signpost but the owl does not tour it.
