# labs/activities-kinds

Lab for new activity kinds (story, words, trace). Read DESIGN.md first.

- Never add an Ainu word, recording or voice here. Real terms pass only
  `validateContentPack` with an approved entry, five review checks and a
  consented `audio` source. Stand-ins must say they are stand-ins.
- Story fact lines cite claims; frame lines state no fact.
- Contract and content changes go through docs/CONTRACTS.md (additive, with tests).
- Before you finish: root `npm test`, lab `npm run build`, update HANDBACK.md.
