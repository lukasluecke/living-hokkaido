# Fonts

Latin subsets downloaded from Google Fonts (2026-11-26), self-hosted so the
app needs no network fonts. Japanese glyphs fall back to system fonts.

- Shippori Mincho B1, weight 700. SIL Open Font License 1.1.
- Zen Maru Gothic, weights 500 and 700. SIL Open Font License 1.1.
